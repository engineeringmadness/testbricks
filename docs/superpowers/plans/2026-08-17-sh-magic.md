# Databricks `%sh` Magic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite `# %sh` / `# MAGIC %sh` notebook comments into `__run_shell__` calls that run `bash -c` via `subprocess`, matching Databricks fail-fast (`-e`) and output behavior.

**Architecture:** Extend `NotebookExecutor` the same way as `%run`: a source transform plus an injected helper. `transform_sh_commands` rewrites comment blocks; `run_shell` calls `subprocess.run(["bash", "-c", script], ...)`; `exec_file` binds `__run_shell__` so top-level, `%run`, and `dbutils.notebook.run()` all work. `ShellCommandError` is a `RuntimeError` for `-e` failures and missing `bash`.

**Tech Stack:** Python 3.14, pytest, stdlib `subprocess` / `re`, existing Testbricks `NotebookExecutor`.

## Global Constraints

- Source forms are comment lines only: `# %sh ...` and `# MAGIC %sh ...`, including consecutive `# MAGIC` body lines.
- Working directory is `os.getcwd()`, not the notebook file directory.
- Shell is `subprocess.run(["bash", "-c", script], cwd=os.getcwd(), env=os.environ.copy(), capture_output=True, text=True)` with `check=False`.
- Print captured stdout to `sys.stdout` and stderr to `sys.stderr` as-is (no extra newline).
- Non-zero exit continues unless `%sh -e`, then raise `ShellCommandError`.
- No new public package export; `__run_shell__` is notebook-namespace only.
- Tests live in `tests/test_sh_magic.py`; import transforms from `testbricks.notebook_executor`.
- Do not mock `subprocess` except the missing-`bash` case.
- YAGNI: no timeout, no Windows branch, no IPython live magics, no `%sql`/`%md`.

### Task 2: `transform_sh_commands`

**Files:**
- Modify: `src/testbricks/notebook_executor.py`
- Test: `tests/test_sh_magic.py`

**Interfaces:**
- Consumes: none from Task 1
- Produces: `transform_sh_commands(source: str) -> str`

Parse full-line comments matching `^\s*#\s*(?:MAGIC\s+)?%sh(?:\s+|$)`. After `%sh`, tokens starting with `-` are flags: `-e` sets `fail_on_error=True`; any other flag raises `ValueError`. The first non-flag token starts the inline script. `# MAGIC` continuations match `^\s*#\s*MAGIC\s+(.*)$` whose body does not start with `%`. `# %sh` without MAGIC is single-line only. Empty/whitespace script emits no call (delete those comment lines). Join body lines with `\n` and do not add an extra trailing newline. Use `{script!r}` and `fail_on_error=True/False`.

```python
SH_START_PATTERN = re.compile(
    r"^(\s*)#\s*(?:MAGIC\s+)?%sh(?:\s+(.*))?\s*$"
)
MAGIC_BODY_PATTERN = re.compile(r"^\s*#\s*MAGIC\s+(.*)$")


def _parse_sh_remainder(remainder):
    fail_on_error = False
    if remainder is None:
        return fail_on_error, ""
    tokens = remainder.split()
    script_start = None
    for index, token in enumerate(tokens):
        if token.startswith("-"):
            if token == "-e":
                fail_on_error = True
            else:
                raise ValueError(f"Unknown %sh flag: {token}")
        else:
            script_start = index
            break
    if script_start is None:
        return fail_on_error, ""
    # Preserve original spacing after flags by slicing the remainder
    # after the flag tokens using the first non-flag token position.
    parts = remainder.split(maxsplit=script_start)
    inline = parts[-1] if parts else ""
    return fail_on_error, inline.strip()


def transform_sh_commands(source):
    lines = source.splitlines(keepends=True)
    output = []
    index = 0
    while index < len(lines):
        line = lines[index]
        newline = "\n" if line.endswith("\n") else ""
        match = SH_START_PATTERN.match(line.rstrip("\n"))
        if not match:
            output.append(line)
            index += 1
            continue
        indent, remainder = match.group(1), match.group(2)
        fail_on_error, inline = _parse_sh_remainder(remainder)
        script_lines = []
        if inline:
            script_lines.append(inline)
        index += 1
        started_with_magic = "MAGIC" in line.upper().split("%sh")[0]
        if started_with_magic:
            while index < len(lines):
                body_match = MAGIC_BODY_PATTERN.match(lines[index].rstrip("\n"))
                if not body_match:
                    break
                body = body_match.group(1)
                if body.lstrip().startswith("%"):
                    break
                script_lines.append(body)
                index += 1
        script = "\n".join(script_lines)
        if script.strip():
            output.append(
                f"{indent}__run_shell__({script!r}, fail_on_error={fail_on_error}){newline}"
            )
    return "".join(output)
```

Detect MAGIC start more reliably: if the start line matches `# MAGIC %sh` (optional space). Use:

```python
started_with_magic = bool(re.match(r"^\s*#\s*MAGIC\s+%sh", line))
```

instead of the `MAGIC in line.upper()` heuristic.

```python
import subprocess
import sys

from testbricks.notebook_exceptions import NotebookExit, ShellCommandError


def run_shell(script, fail_on_error=False):
    try:
        completed = subprocess.run(
            ["bash", "-c", script],
            cwd=os.getcwd(),
            env=os.environ.copy(),
            capture_output=True,
            text=True,
        )
    except FileNotFoundError as exc:
        raise ShellCommandError("bash not found") from exc

    if completed.stdout:
        sys.stdout.write(completed.stdout)
    if completed.stderr:
        sys.stderr.write(completed.stderr)
    if fail_on_error and completed.returncode != 0:
        snippet = (completed.stderr or completed.stdout or "").strip()
        snippet = snippet[-200:]
        raise ShellCommandError(
            f"Command failed with exit code {completed.returncode}: {snippet}",
            returncode=completed.returncode,
        )
```
